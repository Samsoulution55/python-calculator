# Python Projects Repository

Welcome! This repository features simple, interactive Python applications built entirely online in the cloud.

---

## 🧮 1. Python Calculator
A command-line calculator for standard math operations.

### Features
* **Addition / Subtraction / Multiplication / Division**
* Built-in safety checks to block division by zero.

---

## 🎮 2. Number Guessing Game
An interactive mini-game where you compete against the cloud computer.

### Game Rules
* The system randomly selects a secret number between **1 and 100**.
* You have **7 total attempts** to guess it.
* The game guides you with **"Too high"** or **"Too low"** hints after every entry.

---

## 🚀 How to Run the Projects Online
1. Open your **Codespaces** cloud container from the green **`<> Code`** button on this page.
2. In the bottom terminal window, type one of these commands to launch your application:
   * To play the game: `python guessing_game.py`
   * To use the calculator: `python calculator.py`
3. Hit the **Enter** key to start the program!
