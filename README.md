# Python Calculator

A simple, interactive command-line calculator built using Python. This project helps demonstrate the basic concepts of user input, conditional control flows, and functional programming.

## Features
* **Addition** (+)
* **Subtraction** (-)
* **Multiplication** (*)
* **Division** (/) with built-in safety protection against dividing by zero

## How to Run the Project
1. Make sure you have **Python 3** installed on your computer.
2. Open your terminal or command prompt.
3. Run the script using the following command:
   ```bash
   python calculator.py
   ```
